# Awesome Taiwan E-Commerce 台灣電商資源清單

A curated list of platforms, tools, APIs, and open data that Taiwanese e-commerce practitioners actually use. PRs welcome (inclusion criteria: available in Taiwan, working links, not pure advertising).

## Store Platforms

- [SHOPLINE](https://shopline.tw) — one of the largest store platforms by market share in Taiwan, omnichannel (website + POS + social)
- [CYBERBIZ](https://www.cyberbiz.co) — all-in-one store building plus warehousing and logistics
- [91APP](https://www.91app.com) — OMO online-offline integration for large brands
- [EasyStore](https://www.easystore.co) — multichannel sync (Shopee / momo / own site)
- [WACA](https://www.waca.net) — oriented toward small and medium stores
- [meepShop](https://www.meepshop.com) — drag-and-drop editing
- [QDM](https://www.qdm.com.tw) — rich template selection
- [Shopify](https://www.shopify.com/tw) — top choice for cross-border
- [WooCommerce](https://woocommerce.com) — the WordPress ecosystem, the most-used open-source solution in Taiwan

## Payments

- [綠界 ECPay](https://www.ecpay.com.tw) — the largest third-party payment gateway by market share in Taiwan
- [藍新 NewebPay](https://www.newebpay.com) — a long-established gateway with invoice integration
- [TapPay](https://www.tappaysdk.com) — developer-friendly credit card acquiring
- [LINE Pay](https://pay.line.me/tw) — high mobile payment penetration
- [街口支付](https://www.jkopay.com) — local mobile payment

## Logistics

- [綠界物流](https://www.ecpay.com.tw/Business/logistics) — convenience store pickup integration
- [ezShip](https://www.ezship.com.tw) — convenience store store-to-store
- [黑貓宅急便](https://www.t-cat.com.tw) — the main home delivery service
- [新竹物流](https://www.hct.com.tw) — B2B / bulk
